# 09. 유튜브 컨텐츠 포맷 & 정규 코너

> 소율이는 모험가가 아니라 **유튜버**다. 모험은 컨텐츠의 일부일 뿐.
> 2026-03-27

---

## 핵심 원칙

```
"소율이는 유튜버다. 모든 상황을 컨텐츠로 만든다."
```

- 매 에피소드가 "모험 영상"만이 아니라 **다양한 유튜브 포맷**을 포함
- 정규 코너가 있으면 시청자가 기대하는 구조가 생김 → 리텐션 상승
- 러닝 개그와 결합하면 캐릭터성 강화
- Claude가 대본 생성 시 포맷 목록에서 자연스럽게 선택/조합

### 🍜 이세계 먹방 (Isekai Mukbang)

| 서브 포맷 | 설명 | 코미디 포인트 |
|----------|------|-------------|

### ⚔️ 장비 강화 쇼 (Enhancement Show)

| 서브 포맷 | 설명 | 코미디 포인트 |
|----------|------|-------------|
| **강화 도전** | "+1 갑니다! 댓글로 가라/멈춰!" | 성공 환호 or 실패 멘붕 |
| **올인 강화** | 좋은 아이템 고강화 시도 | 날려먹고 울면서 "여러분 때문이에요!!" |
| **남의 장비 강화** | 세리온 검, 리나엘 지팡이 강화 대행 | 남의 거 날려서 인간관계 위기 |
| **도르간의 대장간** | 도르간한테 강화 의뢰 | 도르간 "실패하면 내 탓 아님" |
| **마법 부여 룰렛** | 랜덤 마법 부여 (뭐가 붙을지 모름) | 쓸모없는 마법 붙어서 당황 |
| **합성 도박** | 아이템 2개 합쳐서 새 아이템 | 좋은 거 2개 넣었는데 쓰레기 나옴 |

#### 강화 쇼 연출

```
[강화 전]
소율: "여러분 오늘은 세리온 씨의 검을 +3 강화 합니다!"
세리온: "...조심해라. 그 검은 100년 된 가보다."
소율: "댓글에서 '가라' 가 80%입니다. 갑니다!"

[강화 중]
도르간이 망치를 내려침. 빛이 번쩍.
(성공률 55% — Claude가 결정)

[성공 시]
소율: "됐어요!!! 여러분!!!!" (환호)
세리온: (감동) "...신도들에게 감사를."

[실패 시]
소율: "...어? 검이 왜 이래요?"
세리온: "...뭐?"
검에 금이 가고 빛이 사라짐.
소율: "여러분 도망가야 할 것 같아요" (세리온 분노)
```

#### 강화 실패 → 스토리 연결

강화 실패가 단순 개그로 끝나지 않고 **스토리에 영향**:
- 세리온 검 파괴 → 새 검 찾는 퀘스트 발생
- 리나엘 지팡이 파괴 → 마법학교에서 새 지팡이 구하기
- 소율 스마트폰 강화 실패 → 기능 일부 먹통 (다음 EP 통신 불가)
- 도르간 명성 하락 → 도르간 자존심 회복 이벤트

## 3. 컨텐츠 포맷 DB 구조

### Oracle 테이블

```sql
CREATE TABLE content_formats (
    format_id       VARCHAR2(50) PRIMARY KEY,
    name            VARCHAR2(100) NOT NULL,
    category        VARCHAR2(30),    -- mukbang/enhancement/unboxing/dungeon/vlog/challenge/economy
    description     VARCHAR2(500),
    frequency       VARCHAR2(20),    -- every_ep/frequent/occasional/rare/special
    requirements    JSON,            -- 필요 조건 (장소, NPC, 아이템 등)
    comedy_hooks    JSON,            -- 코미디 포인트 목록
    visual_style    VARCHAR2(30),    -- selfie/overhead/action/casual
    typical_duration_sec NUMBER,
    last_used_ep    NUMBER,
    usage_count     NUMBER DEFAULT 0,
    active          NUMBER(1) DEFAULT 1
);

-- 이세계 음식 DB
CREATE TABLE fantasy_foods (
    food_id         VARCHAR2(50) PRIMARY KEY,
    name            VARCHAR2(100) NOT NULL,
    name_en         VARCHAR2(200),
    source          VARCHAR2(200),   -- 어디서 나오는지
    rarity          VARCHAR2(20),
    taste_profile   JSON,            -- flavor, texture, side_effect, soyul_reaction
    visual          JSON,            -- prompt_tag, cooking_prompt
    nutrition       JSON,            -- hp_restore, buff
    rating          NUMBER(1),       -- 소율이 별점 (1~5, null이면 미평가)
    first_ep        NUMBER,
    created_at      TIMESTAMP DEFAULT SYSTIMESTAMP
);

-- 강화 이력
CREATE TABLE enhancement_log (
    log_id          NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    item_id         VARCHAR2(50) REFERENCES items(item_id),
    owner_id        VARCHAR2(50),
    from_level      NUMBER,
    to_level        NUMBER,          -- 실패 시 하락한 레벨
    success         NUMBER(1),
    destroyed       NUMBER(1) DEFAULT 0,
    cost_gold       NUMBER,
    cost_materials  JSON,
    ep_id           NUMBER,
    audience_vote   VARCHAR2(10),    -- "go" 또는 "stop" (댓글 투표 결과)
    created_at      TIMESTAMP DEFAULT SYSTIMESTAMP
);
```

## 5. 먹방 특별 규칙

### 몬스터 식재료 획득

```
몬스터 처치 → 드롭 테이블에 "식재료" 포함 가능
→ 예: 고블린 처치 → "고블린 이빨" (일반 드롭) + "고블린 다리 고기" (식재료, 30%)
→ 식재료는 fantasy_foods 테이블과 연결
→ 미시식 음식은 소율이가 처음 먹어봄 → 리액션이 대본에 포함
```

### 맛 평가가 스토리에 영향

- ★★★★★ 음식 발견 → 소율이가 그 지역을 자주 방문 (위치 선호도)
- ★☆☆☆☆ 음식 → 해당 종족 NPC와 관계에 미묘한 영향 ("우리 음식 별로래!")
- 독 음식 사고 → HP 감소, 다음 씬에서 아파하는 연출
- 특수 버프 음식 → 다음 전투에서 실제 스탯에 반영
