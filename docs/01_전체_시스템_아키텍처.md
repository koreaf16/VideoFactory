# 01. 전체 시스템 아키텍처

> 이세계 유튜버 × AI 영상 공장
> 2026-03-27

---

## 프로젝트 한 줄 요약

고등학생 유튜버가 이세계에서 모험하는 AI 영상 시리즈.
시청자 댓글이 스토리에 실시간 반영되고, 구독자 수가 주인공의 마력이 된다.

---

## 기술 스택

| 레이어 | 기술 | 역할 |
|--------|------|------|
| Orchestrator | Node.js (TypeScript) | 전체 파이프라인 제어, 웹 UI, API |
| AI Services | Python (FastAPI) | Claude API, Qwen3-TTS, 임베딩, Whisper |
| GPU Engine | ComfyUI | Flux 2 (이미지), Wan 2.2 (영상), ESRGAN (업스케일) |
| Database | Oracle AI Database 26ai | Vector + Graph + Relational + JSON 통합 |
| Post-Process | FFmpeg | 합성, 오버레이, 글리치, 환경음 |
| External | YouTube API | 업로드, 댓글 수집, Analytics |

## 프로덕션 사이클 (1 에피소드)

```
1. 댓글 수집 (YouTube API)
   ↓
2. 댓글 분석 (임베딩 → 클러스터 → Claude 분석)
   ↓
3. 대본 생성 (Oracle Hybrid Search → Claude 쇼러너)
   ↓  웹 UI에서 검수/수정/승인
4. 영상 생성
   ├─ Pass 1: Flux → 키프레임 이미지 (전체 씬)
   ├─ Pass 2: Wan 2.2 → I2V 영상화 (전체 씬)
   └─ 병렬: TTS 음성 + BGM/효과음 선택
   ↓
5. 후처리 (FFmpeg)
   ├─ 스마트폰 UI 오버레이
   ├─ 손떨림 + 노이즈
   ├─ 댓글 텍스트 삽입 ("신탁의 시간")
   ├─ 글리치 이펙트 (4th wall용)
   ├─ 환경음 + BGM 믹싱
   └─ 클립 합치기
   ↓  웹 UI에서 최종 검수
6. 배포 (YouTube Upload API)
   ↓
7. 피드백 루프
   ├─ 댓글 수집 → Oracle 저장
   ├─ 구독자 수 → voice_resonance 업데이트
   ├─ NPC 인기도 업데이트
   ├─ 프레임/프롬프트 레퍼런스 자동 수집
   └─ → 다시 1번으로
```

## 세계관 핵심 설정

| 항목 | 내용 |
|------|------|
| 장르 | 코미디/혼돈 이세계 판타지 |
| 주인공 | 한소율 (17세, 고등학생 유튜버) |
| 핵심 설정 | 구독자 = 마력, 댓글 = 신탁 |
| 파티 | 태양(기사), 린(엘프 마법사), 나비(도적) |
| 리얼리즘 | 스마트폰 브이로그 느낌 (NOT anime) |
| 시청자 참여 | 댓글이 스토리에 실시간 반영 |
| 비주얼 | Flux 2 실사 → Wan 2.2 영상화 → FFmpeg 후처리 |

## Oracle 26ai 4개 데이터 모델 역할

| 모델 | 저장 대상 | 핵심 용도 |
|------|----------|----------|
| Vector DB | 얼굴/장면/음성/프롬프트/댓글 임베딩 | 유사도 검색, 품질 검증, 참조 이미지 자동 선택 |
| Property Graph | 캐릭터 관계, NPC 생애, 시청자 감정, 세력도 | 스토리 컨텍스트, 관계 변화 추적 |
| Relational | 에피소드, 씬, LoRA 이력, VR 시계열, 댓글 통계 | 구조화된 메타데이터, 이력 추적 |
| JSON Duality | 캐릭터 프로필, 대본, 설정, mood | 유연한 문서 저장, 스키마 없는 데이터 |

**Unified Hybrid Search**: 단일 SQL로 4개 모델 통합 조회 → Claude 컨텍스트 주입
