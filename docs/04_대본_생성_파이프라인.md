# 04. 대본 생성 파이프라인

> Oracle Hybrid Search → Claude 쇼러너 → 웹 UI 검수 → DB 저장
> 2026-03-27

---

## 전체 흐름

```
Oracle Hybrid Search (자동, 6가지 데이터 수집)
    ↓
Node.js → Python FastAPI → Claude API (대본 JSON)
    ↓
웹 UI (사람이 검수/수정/승인)
    ↓
Oracle DB 저장 (episodes + scenes + Graph 업데이트)
    ↓
영상 생성 파이프라인으로 전달
```

---

## 1. Oracle 컨텍스트 자동 수집 (6가지)

| # | 데이터 | Oracle 모델 | 용도 |
|---|--------|------------|------|
| ① | 캐릭터 상태 (mood, VR, arc) | Relational + JSON | 현재 캐릭터 심리 |
| ② | 캐릭터 간 관계 (trust) | Graph (GRAPH_TABLE) | 갈등/우정 반영 |
| ③ | 시청자 여론 (감정, 요청) | Vector 클러스터 + Relational | 댓글 반영 |
| ④ | 최근 3화 줄거리 | Relational | 연속성 유지 |
| ⑤ | 러닝 개그 목록 | Relational | 코미디 일관성 |
| ⑥ | 고품질 프롬프트 패턴 | Vector Search | 프롬프트 품질 보장 |

### 핵심 쿼리: Unified Hybrid Search

```sql
-- 단일 호출로 캐릭터 + 관계 + 여론 + 에피소드 통합
SELECT c.name, c.profile, c.mood, c.voice_resonance,
       r.rel_type, r.trust,
       vs.positive, vs.negative, vs.requests,
       e.synopsis
FROM characters c
LEFT JOIN char_relationships r ON c.char_id = r.from_char_id
LEFT JOIN viewer_sentiments vs ON c.char_id = vs.char_id
    AND vs.ep_id = (SELECT MAX(ep_id) FROM episodes)
LEFT JOIN episodes e ON e.ep_id >= (SELECT MAX(ep_id)-2 FROM episodes)
WHERE c.char_id IN (:main_ids)
```

## 2. Claude 쇼러너 호출

### 시스템 프롬프트 (고정)

```
이세계 유튜버 시리즈 쇼러너.
코미디/혼돈 톤. 구독자=마력, 댓글=신탁.

원칙:
- 시청자 여론 30% 수용, 70% 의외의 방향
- 러닝 개그 매 에피소드 최소 2개
- 씬마다 ComfyUI 영문 프롬프트 + 모션 프롬프트
- 스마트폰 브이로그 리얼리즘
- decision_reasoning 필수 기록
```

## 3. 신탁의 시간 (댓글 읽기 코너)

매 에피소드 도입부에 자동 생성:

```sql
-- 이전 에피소드 인기 댓글 상위 10개
SELECT author, text_content, likes
FROM youtube_comments
WHERE ep_id = :prev_ep AND likes >= 10
ORDER BY likes DESC
FETCH FIRST 10 ROWS ONLY
```

Claude에게 10개 중 5개를 골라 "소율이가 읽고 NPC가 반응하는" 코너 대본 요청.

## 4. 웹 UI — 대본 검수

### 기능

- 대사 직접 수정 (인라인 에디터)
- 씬 순서 드래그 변경
- 씬 삭제/추가
- "이 씬 다시 써줘" → Claude 재생성 (해당 씬만)
- ComfyUI 프롬프트 직접 수정
- 엔딩 훅 수정
- "전체 다시 생성" → 컨텍스트 유지, 대본만 재생성

### 승인 후 자동 처리

1. `episodes` INSERT
2. `scenes` 씬별 INSERT
3. Graph DB 관계/감정 업데이트 예약
4. `running_gags` 사용 횟수 업데이트
5. 영상 생성 큐(BullMQ)에 작업 등록

## 5. API 엔드포인트

```
POST   /api/episodes/generate          대본 생성 (Oracle→Claude)
GET    /api/episodes/:epId/draft       대본 초안 조회
PUT    /api/episodes/:epId/scenes/:id  씬 개별 수정
POST   /api/episodes/:epId/scenes/:id/regenerate  씬 재생성
POST   /api/episodes/:epId/approve     승인 → DB + 큐 등록
DELETE /api/episodes/:epId/draft       폐기 → 재생성
GET    /api/episodes/:epId/context     Oracle 컨텍스트 확인
```
