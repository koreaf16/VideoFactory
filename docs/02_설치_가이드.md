## 신규 설치 항목

### A. Flux 2 모델

#### A-1. ComfyUI-GGUF 업데이트

```bat
cd D:\ComfyUI\ComfyUI\custom_nodes\ComfyUI-GGUF
git pull
```

#### A-2. text_encoders 폴더 생성

```bat
mkdir D:\ComfyUI\ComfyUI\models\text_encoders
```

#### A-3. Flux 2 Klein 9B (주력) 다운로드

```bat
:: GGUF 모델 (~7GB)
hf download unsloth/FLUX.2-klein-9B-GGUF flux-2-klein-9b-Q5_K_M.gguf --local-dir D:\ComfyUI\ComfyUI\models\unet

:: 텍스트 인코더 (~8.66GB)
hf download Comfy-Org/flux2-klein-9B split_files/text_encoders/qwen_3_8b_fp8mixed.safetensors --local-dir D:\ComfyUI\ComfyUI\models\text_encoders

:: VAE (~335MB)
hf download Comfy-Org/flux2-klein-9B split_files/vae/flux2-vae.safetensors --local-dir D:\ComfyUI\ComfyUI\models\vae
```

#### A-4. 파일 위치 정리 (하위 폴더에 들어간 경우)

```bat
if exist "D:\ComfyUI\ComfyUI\models\text_encoders\split_files\text_encoders\qwen_3_8b_fp8mixed.safetensors" (
    move "D:\ComfyUI\ComfyUI\models\text_encoders\split_files\text_encoders\qwen_3_8b_fp8mixed.safetensors" "D:\ComfyUI\ComfyUI\models\text_encoders\"
    rmdir /s /q "D:\ComfyUI\ComfyUI\models\text_encoders\split_files"
)
if exist "D:\ComfyUI\ComfyUI\models\vae\split_files\vae\flux2-vae.safetensors" (
    move "D:\ComfyUI\ComfyUI\models\vae\split_files\vae\flux2-vae.safetensors" "D:\ComfyUI\ComfyUI\models\vae\"
    rmdir /s /q "D:\ComfyUI\ComfyUI\models\vae\split_files"
)
```

#### A-5. Flux 2 Dev (하이엔드, 선택) 다운로드

```bat
:: GGUF 모델 (~19GB)
hf download city96/FLUX.2-dev-gguf flux2-dev-Q4_K_M.gguf --local-dir D:\ComfyUI\ComfyUI\models\unet

:: 텍스트 인코더 FP4 (~12GB, 3090 권장)
hf download Comfy-Org/flux2-dev split_files/text_encoders/mistral_3_small_flux2_fp4_mixed.safetensors --local-dir D:\ComfyUI\ComfyUI\models\text_encoders
```

#### A-6. HuggingFace 리포 정리

| 용도 | 리포 |
|------|------|
| Klein 9B GGUF | `unsloth/FLUX.2-klein-9B-GGUF` |
| Klein 텍스트 인코더 + VAE | `Comfy-Org/flux2-klein-9B` |
| Dev GGUF | `city96/FLUX.2-dev-gguf` |
| Dev 텍스트 인코더 | `Comfy-Org/flux2-dev` |

#### A-7. Flux 2 ComfyUI 설정

| 항목 | 값 | 주의 |
|------|-----|------|
| CFG | **3.5** | 7 이상 절대 X (과포화) |
| Steps | **20** (Klein은 4~8도 가능) | |
| 네거티브 프롬프트 | **안 씀** | Flux 2는 무시 |
| 텍스트 인코더 | **1개** | Flux 1의 DualCLIP과 다름 |
| CLIPLoader type | **flux** | 반드시 지정 |
| Sampler | **euler** | |
| Scheduler | **simple** | |
| 해상도 | **1024×1024** | |

#### A-8. VRAM 사용량 (3090 24GB)

| 구성 | VRAM | 속도 |
|------|------|------|
| Klein 9B Q5 + Qwen FP8 | ~16GB | 3~5초/장 |
| Klein 9B Q8 + Qwen FP8 | ~20GB | 5~8초/장 |
| Dev Q4 + Mistral FP4 | ~22GB+ | 60~120초/장 |
| Wan 2.2 I2V | ~18GB | Flux와 동시 불가 |

### B. Node.js 프로젝트 초기화

```bat
mkdir D:\ComfyUI\server
cd D:\ComfyUI\server

npm init -y
npm install typescript ts-node @types/node --save-dev
npx tsc --init

npm install express ws oracledb bullmq sharp fluent-ffmpeg
npm install @types/express @types/ws --save-dev
```

#### package.json scripts

```json
{
  "scripts": {
    "dev": "ts-node app.ts",
    "build": "tsc",
    "start": "node dist/app.js"
  }
}
```

### C. Python FastAPI (LLM 전용)

```bat
mkdir D:\ComfyUI\llm-server
cd D:\ComfyUI\llm-server

python -m venv venv
venv\Scripts\activate

pip install fastapi uvicorn httpx
pip install sentence-transformers
pip install qwen-tts soundfile
pip install openai-whisper
```

#### 실행

```bat
cd D:\ComfyUI\llm-server
venv\Scripts\activate
uvicorn main:app --host 0.0.0.0 --port 8000
```

Node.js → `http://localhost:8000/api/...` 로 호출
